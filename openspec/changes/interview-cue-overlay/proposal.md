## Why

Retrieved evidence is only useful during an interview if it appears in a compact, glanceable, non-disruptive near-camera presentation.

## What Changes

- Add dedicated cue overlay window consuming `InterviewCue` state.
- Show listening/retrieving/ready/no-match/unavailable states.
- Persist presentation preferences but never cue content.
- Add direct hide/clear/readability controls without stopping transcription.

## Capabilities

### Modified Capabilities
- `interview-cue-overlay`
