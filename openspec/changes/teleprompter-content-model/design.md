## Decisions

### D1. Markdown is primary authoring format
Headings start sections; plain text produces one section.

### D2. Stable IDs
Derive from source-relative order plus normalized heading/content digest so unchanged sections remain stable.

### D3. Keep authored and matching forms separate
Never mutate display text for alignment normalization.

### D4. User-owned source remains external
Prepared interview scripts/outlines are runtime content and not committed to this repository.
